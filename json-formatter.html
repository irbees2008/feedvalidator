JSON Formatter

Форматирование, минификация и проверка JSON прямо в браузере, данные никуда не отправляются.

Отступ

Что делает JSON Formatter

Инструмент проверяет JSON на синтаксические ошибки, показывает строку и столбец, где разбор остановился, приводит данные к читаемому виду с отступами или сжимает их в одну строку. Это удобно при отладке API, конфигураций и JSON Feed.

Кратко Вставьте JSON и нажмите «Форматировать» или «Минифицировать». Данные не покидают ваш браузер.

Частые ошибки в JSON

  • Одинарные кавычки вместо двойных: {'a': 1}.
  • Запятая после последнего элемента: [1, 2,].
  • Ключи без кавычек: {a: 1}.
  • Комментарии: JSON их не поддерживает.
  • Значения undefined, NaN и Infinity недопустимы.

FAQ

Отправляются ли данные на сервер?

Нет, разбор и форматирование выполняются в браузере.

Сохраняются ли большие числа точно?

Нет: числа за пределами точности JavaScript (больше 253) при форматировании могут округлиться.
