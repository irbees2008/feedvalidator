Meta Tags Analyzer

Анализ мета-тегов HTML: title, description, canonical, robots, Open Graph и Twitter Card. Проверка в браузере, данные никуда не отправляются.

ТегЗначениеПроверка

Что проверяет анализатор

Инструмент разбирает вставленный HTML и показывает, какие мета-теги найдены: title, description, robots, canonical, viewport, язык страницы, Open Graph и Twitter Card. Для каждого тега проверяется наличие и длина, а также типичные ошибки.

Кратко Вставьте HTML и нажмите «Проанализировать». HTML разбирается без выполнения скриптов и не отправляется на сервер.

Рекомендации

  • title: примерно 30–60 символов, уникален для каждой страницы.
  • description: примерно 70–160 символов.
  • canonical: абсолютный адрес основной версии страницы.
  • og:title, og:description, og:image, og:url нужны для красивого превью в соцсетях.
  • noindex в robots закрывает страницу от поисковиков.

FAQ

Можно проверить страницу по адресу?

Для проверки по URL с загрузкой страницы с сервера используйте Open Graph Checker.

Выполняются ли скрипты из вставленного HTML?

Нет, разбор идёт через DOMParser, скрипты и картинки не загружаются.
