Установка и локальный запуск

Актуальные требования для запуска проекта, а не исторические инструкции Feed Validator.

← К документации

Требования

  • Python 3.12.x. Проект использует стандартный модуль cgi, удалённый в Python 3.13.
  • Apache с CGI (mod_cgi или mod_cgid) и поддержкой правил .htaccess.
  • Пакеты из корневого requirements.txt.
  • Для PHP Compatibility Checker дополнительно нужен CLI PHP с расширением tokenizer.

OSPanel на Windows

  1. Установите Python 3.12 в C:\OSPanell\modules\python\ и проверьте наличие python.exe.
  2. Установите зависимости командой: 
    C:\OSPanell\modules\python\python.exe -m pip install -r C:\OSPanell\home\feedvalidator.ru\requirements.txt
  3. Включите CGI для Apache в настройках OSPanel и настройте домен на каталог проекта C:\OSPanell\home\feedvalidator.ru.
  4. Убедитесь, что первая строка CGI-файлов указывает на используемый Python, перезапустите Apache и откройте локальный домен.

VPS с Linux и Apache

  1. Установите Python 3.12, Apache и зависимости проекта в виртуальное окружение вне каталога сайта.
  2. Настройте виртуальный хост, включите CGI и Rewrite, разрешите необходимые правила .htaccess.
  3. В CGI-файлах укажите путь к интерпретатору виртуального окружения; разрешите запуск CGI и проверьте владельца файлов.
  4. Настройте HTTPS и проверьте журналы Apache, если CGI возвращает ошибку 500.

Проверка

Для тестов используйте Python 3.12 из корня проекта:

C:\OSPanell\modules\python\python.exe runtest.py

В текущем наборе часть старых сценариев валидатора остаётся известной регрессией; успешный запуск команды не означает, что все тесты прошли. Точные актуальные шаги настройки Apache и разбор ошибок описаны в документации проекта.

Новые сетевые CGI-инструменты используют ограниченные запросы только к публичным адресам; перед публикацией проверьте настройки CGI и права доступа на целевом сервере.
