Шрифты для сайта

Просматривайте шрифты из каталога, готовьте CSS-подключение и конвертируйте файлы прямо в браузере.

Каталог и предпросмотр

Файлы сайта берутся из папки fonts/. Чтобы обновить список после добавления или удаления шрифтов, запустите python docs-xml/build-font-catalog.py.

Поддерживаются TTF, OTF, WOFF, WOFF2, EOT и SVG Font. Файл читается в памяти браузера и не отправляется сайту.

Съешь ещё этих мягких французских булок, да выпей чаю.

Выберите шрифт из каталога или с устройства.

Конвертация

Выберите форматы для скачивания. Конвертация выполняется локально в браузере; файлы не загружаются на сервер. OTF можно открыть и преобразовать, но создать файл OTF этим инструментом нельзя.

Модуль конвертации и WOFF2-компонент загружаются с jsDelivr по HTTPS. Содержимое шрифта остаётся в браузере. Используется fonteditor-core 2.6.3 (MIT).

Форматы результата

    Пример подключения

    Положите файлы веб-шрифта в fonts/. Для современных браузеров используйте WOFF2, оставив WOFF как запасной вариант. В имени файла и CSS-коде ниже укажите свои файлы.

    CSS: объявление шрифта и применение

    @font-face {
  font-family: 'SiteFont';
  src: url('/fonts/site-font.woff2') format('woff2'),
       url('/fonts/site-font.woff') format('woff');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: 'SiteFont', Arial, sans-serif;
}

    HTML

    <p>Текст с подключённым шрифтом</p>

    Подключение в таблице стилей

    <link rel="stylesheet" href="/css/site-fonts.css">

    Если используете переменные шрифты, укажите диапазон, например font-weight: 100 900;, только когда файл действительно содержит такие начертания. Для обычного статического файла задайте конкретное значение веса.

    Как добавить шрифт в каталог

    1. Создайте папку fonts/ в корне сайта и скопируйте туда файлы шрифтов.
    2. Из корня проекта выполните python docs-xml/build-font-catalog.py. Скрипт обновит fonts/catalog.txt.
    3. Перезагрузите эту страницу. Шрифты появятся в списке предпросмотра.
    4. После конвертации скопируйте нужные файлы в папку сайта и обновите CSS-ссылки.

    Шрифты обычно распространяются по лицензии. Убедитесь, что лицензия разрешает размещение файлов на вашем сайте и конвертацию.
