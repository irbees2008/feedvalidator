Редактор Markdown

Пишите в Markdown с живым предпросмотром и экспортируйте в .md или HTML — прямо в браузере.

Вид
Предпросмотр

Что такое редактор Markdown?

Markdown — это лёгкий язык разметки: заголовки, выделение, списки, ссылки и код пишутся обычными символами (#, *, -, `), а затем превращаются в аккуратный HTML. Его используют в README на GitHub, документации, заметках, блогах и чатах.

Онлайн-редактор показывает результат сразу, пока вы печатаете: слева исходный текст, справа готовая страница. Так проще заметить ошибку в разметке, подготовить README или описание релиза и быстро получить чистый HTML для вставки на сайт.

Кратко Пишите в левой панели, смотрите результат справа, затем копируйте HTML или скачивайте файл. Текст не покидает ваш браузер.

Как пользоваться редактором

  1. 1

    Начните печатать

    Введите текст в левой панели или нажмите «Загрузить пример». Предпросмотр обновляется при каждом изменении.

  2. 2

    Добавьте структуру

    Используйте кнопки над редактором или горячие клавиши: Ctrl+B — жирный, Ctrl+I — курсив, Ctrl+K — ссылка.

  3. 3

    Выберите вид

    «Разделённый» показывает обе панели, «Редактор» — только текст, «Предпросмотр» — только результат. Это удобно на телефоне.

  4. 4

    Скопируйте или сохраните

    Скопируйте готовый HTML или Markdown, либо скачайте файл .md или самостоятельную страницу .html.

FAQ по Markdown

Как преобразовать Markdown в HTML?

Введите текст в редакторе и нажмите «Копировать HTML» или «Скачать .html». Вы получите разметку, готовую для вставки на страницу, либо отдельный HTML-файл с базовыми стилями.

Чем GitHub-Flavored Markdown отличается от обычного?

GFM добавляет таблицы, списки задач, зачёркивание и автоматические ссылки. Редактор поддерживает эти расширения, поэтому README из GitHub отображается почти так же.

Можно ли вставлять HTML внутрь Markdown?

В этом редакторе HTML-теги не выполняются: они показываются как обычный текст. Так нельзя случайно запустить чужой скрипт, а предпросмотр остаётся безопасным.

Почему не отображается картинка?

Разрешены только адреса http:// и https://. Локальные пути и данные других типов в предпросмотре блокируются.

Редактор приватный?

Да. Текст обрабатывается только в вашем браузере и не отправляется на сервер. Черновик сохраняется локально в этом браузере, и его можно стереть кнопкой «Очистить».
